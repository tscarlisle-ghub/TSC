Reorganize a folder, with full control and a safety net.

Pick a folder anywhere on disk — Dropbox, iCloud, Desktop, an external drive. The tool will read its contents, propose a cleaner structure, and let you reshape that structure visually before anything on disk changes.

What this tool will do

  • Walk every file in the folder you choose and identify file types, duplicates, and likely junk.
  • Propose a new structure organized by type, date, or project — you pick the strategy.
  • Show the proposed tree visually so you can drag, rename, add, and remove folders before committing.
  • On execute: snapshot the current folder to a timestamped backup, then move files to their new homes.
  • Send duplicates and likely-junk to a _Review-for-Deletion folder. Nothing is ever permanently deleted.

Important notes about Dropbox & iCloud

To reorganize a Dropbox or iCloud folder, point this tool at its local sync folder (e.g. ~/Dropbox/Projects or ~/Library/Mobile Documents/com~apple~CloudDocs/Projects). Cloud sync will pick up the changes automatically. Files that are online-only (not yet downloaded locally) will be skipped — download them first if you want them included.

Tip: nothing happens on disk until you reach the Review step and confirm. You can back out at any time before then.

      Restoring

      If you want to undo this reorganization, every original file lives in the backup folder. The backup also contains manifest.json mapping original path → new path for every file that was moved. You can restore manually by copying from the backup, or paste the manifest to a developer to script a reverse operation.

      The backup will remain on disk until you delete it manually. Once you're satisfied with the new layout, you can drag the backup to the Trash to reclaim the space.
