      Settings & Data Source

      Data Source — TSC-BILLING repository

      Client list and fee structures are pulled from the same data.json used by your billing dashboard. Provide a fine-scoped GitHub PAT with Contents: Read and write permission on the billing repo so this app can both fetch the latest clients and save new ones you add here back to the same file.

      No PAT? Use Load local data.json to pick a copy from your computer for testing — you can save changes back to GitHub once you add a token.

      Backup & Restore (this app's preferences)

      About

      TSC-CONT generates AIA B105-2017 Supplementary Conditions documents, sharing client and fee data with the TSC-BILLING dashboard. Designed using Edward Tufte's principles of analytical design. Typeset in Warnock Pro, Interstate, DIN Condensed Variable, and FF Meta Correspondence.
