Settings & GitHub Sync

Fiscal Year

Defaults to the current calendar year on each load. Override here temporarily to look at past invoices and totals — your choice applies for this session only and resets on next load.

GitHub Repository

Data is stored as data.json at the path you specify. Token is kept in your browser only. Create a fine-scoped PAT with Contents: Read and write permission on this repository only.

Once your token is saved, the dashboard automatically saves to GitHub 90 seconds after your last change. You can also click Save to GitHub in the header at any time to save immediately.

Pushes data.json to GitHub immediately.

Backup & Restore

All your client and invoice data is stored as a single file. Download Backup saves a copy to your computer (use this before making big changes, or for archival). Restore from Backup replaces all current data with what's in a backup file you choose. Backup files are plain text — you can open them in any text editor if needed. Different from "Save to GitHub" in the header (which syncs the live data file in your repo); these are local copies on your computer.

Local Copy on Save

When enabled, every successful Save to GitHub also downloads a fresh data.json via your browser. To make it land in your working folder, set your browser's default download location to that folder (Safari: Preferences → General → File download location), or choose "Ask for each download" to pick the destination each time.

Accountant Export

Generate a multi-tab Excel workbook (.xlsx) for a specific tax year. You'll be prompted for the year. The workbook contains: Year Summary (cash + accrual income, A/R, YoY), By Client for that year, All Invoices dated in that year, A/R Aging bucketed 0-30 / 31-60 / 61-90 / 90+, and Fee Structure (lifetime view). For the current fiscal year the Year Summary also includes the year-end projection.

Firm Information

Appears on all generated Word document invoices.

Advanced click to show — contains destructive operations

Reset All Data

Wipes every client, invoice, and fee structure in this dashboard and replaces them with an empty starting state. This cannot be undone. Always download a backup first using the Backup & Restore section above. If you have GitHub sync configured and saved recently, you can also recover from your repository's commit history.
